## Key concepts learned
**Module 1 — key success tips**
- Learn by doing: take every practice opportunity.
- Build a portfolio of projects.
- Share work on LinkedIn to maximize reach.

**Portfolio decision**
- One public repo under my personal GitHub (not an org); each `modules/NN-slug/` folder is a self-contained project with its own README.
- Flagship projects can later be split into their own repos with history via `git subtree split --prefix=modules/NN-slug -b <branch>`; separate repos can be pinned individually on the profile.

**Module 2 — skill idea: college project deliverables**
- Problem: each project stage needs a report, a PowerPoint deck, and spreadsheets, all built by hand by the team.
- Idea: one skill per deliverable (or one skill with three outputs) that generates a first draft from project inputs, so the team only reviews and edits.
- Needed before building: the college's templates/format rules (report structure, slide template, sheet layout), and what each stage requires.

**Module 2 — learning objectives**
1. Explain Claude Cowork and how its parts (skills, plugins, connectors) fit together.
2. Use existing skills/plugins to automate workflows.
3. Build and deploy custom skills and plugins for specific needs.
4. Automate scheduling, organize information, run multi-step workflows (e.g. deep research + document synthesis).
5. Apply Cowork to business cases: marketing, finance/financial analysis, competitor research.
6. Design and build a practical real-world Cowork project.

**Doing Module 2 on omp (company moved from Claude to omp / OmniRoute)**
| Cowork concept | omp equivalent |
|---|---|
| Skills | Same `SKILL.md` format. omp loads `.omp/skills/<name>/SKILL.md` (project), `~/.omp/agent/skills/` (user), and also Claude's skill folders, so one skill works in both. Run with `/skill:<name>`. |
| Plugins | `omp plugin install`; omp also reads Claude marketplace plugins (skills, commands, hooks, MCP servers). |
| Connectors | MCP servers configured in `.omp/mcp.json` (project) or the user `mcp.json`. |
| Deep research / synthesis | Subagents run in parallel, plus web search. |
| Scheduled tasks | No built-in scheduler found yet: use cron / Windows Task Scheduler calling `omp` in print mode. |
- Plan: watch the videos for the concepts, build every exercise as an omp skill/plugin in this repo.
- For the Cowork-interface lectures: use **Freebuff** ([freebuff.com](https://freebuff.com), free agent with a Cowork mode; costs "freebucks" per hour, runs on smaller models). Save it for things only the interface shows; do the real building in omp.
